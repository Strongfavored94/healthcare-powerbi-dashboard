# Healthcare Staffing Cost Analysis Dashboard

## Project Overview
This project analyzes hospital staffing levels and labor costs across departments using Power BI.

## Tools Used
- Power BI
- DAX
- Data Modeling

## Key Insights
- ICU has the highest labor cost
- RN roles contribute the largest portion of labor expenses
- Emergency department has the highest staff count

## Business Impact
This analysis helps hospital administrators identify cost drivers and optimize staffing decisions.
